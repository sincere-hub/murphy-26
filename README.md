# 🎂 Murphy's 26th Birthday Card

A playful, interactive birthday card built with **HTML, CSS & JavaScript** — no frameworks, no build step. Just open and celebrate.

![HTML](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)

---

## ✨ Features

- 🎨 Animated **glassmorphism** birthday card
- 🎉 **Confetti burst** on button click (80 pieces, randomized)
- 🎈 Floating **balloons** drifting up the background
- 😄 Random **Murphy's Law jokes** every time you click
- 🌈 Shimmering gradient title + pulsing "26"
- 📱 Fully **responsive** — works on phone and desktop
